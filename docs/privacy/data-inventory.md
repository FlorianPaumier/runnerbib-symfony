# Personal-data inventory

Implementation inventory, 2026-10-10. This records the local schema and adapters, not a compliance determination or completed retention rollout. Product requirements remain authoritative; unresolved durations and review procedures are in DEC-03/04. Account and subscription UUIDs remain linkable personal data.

Before PRIV-01/02/03 can be completed, agree purpose/text versions and category durations, implement request/export/deletion orchestration and holds, test private-field redaction without financial-history mutation, and rehearse restoration so deleted data does not reappear.
